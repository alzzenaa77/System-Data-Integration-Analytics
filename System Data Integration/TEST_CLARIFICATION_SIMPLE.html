🧪 Test Clarification Flow

Step 0: Clear All Data (WAJIB!)

Klik tombol ini DULU sebelum test!

Step 1: Open App

Step 2: Manual Testing

  1. Login sebagai contributor1 / password123
  2. Submit fee data baru
  3. Logout, login sebagai validator1 / password123
  4. Klik "Clarify" pada data
  5. Logout, login kembali sebagai contributor1
  6. Klik "Submit Clarification"
  7. CHECK: Status = "PENDING", Action = "Clarification Submitted"

Step 3: Verify Results

Setelah submit clarification, yang HARUS terjadi:

  • ✅ Status badge: PENDING
  • ✅ Action column: ⏳ Clarification Submitted

Jika masih menunjukkan "NEEDS_CLARIFICATION", berarti data lama masih ada!
